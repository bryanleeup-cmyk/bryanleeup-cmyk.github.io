04.30

东京 · 银座到涩谷

  • 台场 Animeal → 银座 → 东京塔 → 涩谷十字路口与忠犬八公。
  • 出发前入住上海如家驿居酒店（上海虹桥机场会展中心店）（¥116.10）。

05.01

浅草、秋叶原与新宿

  • 浅草寺 → 晴空塔 → 秋叶原 → 烧肉 → 新宿歌舞伎町 → 涩谷。

住宿东京新桥

05.02

镰仓与江之岛

  • 镰仓大佛 → 稻村崎 / 七里滨远眺富士山 → 镰仓高校前 → 江之岛。

住宿东京新桥

05.03

富士山与河口湖

  • 罗森 → 河口湖 → 日川时计店 → 新仓山浅间神社。
  • 晚上搭夜间巴士前往关西。

住宿夜间巴士

05.04

京都东山

  • 清水寺 → 三年坂 → 二年坂 → 法观寺 → 高台寺 → 八坂神社 → 祇园 → 鸭川。

住宿京都

05.05

京都的寺院与城

  • 伏见稻荷大社 → 三十三间堂 → 原文「平等寺」→ 二条城。
  • 备选：岚山 → 渡月桥 → 竹林小径。

住宿京都

05.06

宇治与奈良

  • 宇治站 → 中村藤吉本店 → 平等院 → 宇治川与宇治桥 → 宇治神社 → 宇治上神社。
  • 接着去奈良：春日大社 → 若草山 → 二月堂 → 东大寺 → 奈良公园 → 中谷堂。
